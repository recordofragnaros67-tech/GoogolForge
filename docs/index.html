Your AI coding team, in your pocket.

GoogolForge turns an Android phone into an offline AI coding forge. It runs in Termux with local Ollama models: no cloud, no API keys, no cost.

Install in one lineView on GitHub

Install

Open Termux on Android (from F-Droid), connect to Wi-Fi (about 2.3 GB of models), and paste:

curl -fsSL https://raw.githubusercontent.com/recordofragnaros67-tech/GoogolForge/main/install.sh | bash

Setup finishes with health checks. Then type forge for commands or gf to talk in plain English.

What it does

AI Team

forge team: Architect, Coder, Tester and Referee build and test code together.

Genius mode

forge bench --genius: a Smart Router sends hard tasks to the 3B model, and drafts are scored by agreement.

Benchmark Arena

forge bench --elite: sealed judge; hidden tests are never shown to the model.

Mutation testing

forge mutate: plants bugs and scores your tests out of 100.

Code memory

forge rag: answers questions about your own code.

Academy

Lessons, quizzes and drills, with ranks from Pawn to Grandmaster.

Dashboard

forge web: installable, token-protected phone dashboard.

Model Shootout

forge shootout --apply: finds the best model and prompt style for your phone.

Auto-Publish

Pushes to GitHub only when code passes compile and test gates.

The genius method

  1. Deep preparation. The Architect writes a spec and tests before any code.
  2. Several candidate moves. Elite mode drafts three solutions and lets the tests choose.
  3. Self-repair. Failures are fixed from the error type only, so the judge stays honest.
  4. Two-model review. A second model checks the work before it ships.

Safety

AI-written code that uses risky calls (eval, exec, sockets, network) is blocked until you approve it. CI runs every self-test, a Bandit security scan and a secret scan on each push.
